# PDF 交付：默认版式与验收

## 选择实现

先检查现有 Markdown／Word 源稿、图源、构建脚本和依赖，复用能满足要求的渲染路径。用户给参考 PDF 时先检查其层级、密度、图表比例和页面节奏，再决定如何借鉴。文字和图示内容仍以本次研究为准。

复用当前环境的 PDF、文档或 Markdown 排版工具及相应技能，运行时确认字体与程序路径。

## 中文默认版式

这些是个人偏好；用户模板或本次要求可以覆盖。

- 正文采用宋体字族，正文加粗仍为宋体字族的粗体；标题使用黑体。
- 选择有实际粗字重、完整中文字形的宋体，例如可用的思源宋体／Noto Serif CJK／SC。需要时从可变字体导出静态字重。核实字体许可及嵌入能力，不依赖查看器自动替换。
- 中文双引号匹配相邻正文或标题的字体与字重，避免落入西文字体后形状、基线异常。中文标点禁则、英文字母与中文间距按实际排版检查。
- 明确正文、标题、图注、表头的层级。通过段落与留白形成结构，避免装饰元素占据研究内容空间。
- 按内容检查科学符号、公式、单位、上下标、变量与代码标识；化学结构或专业工程标记出现时另核对其字形。字体需支持实际使用的字符。

## 表格排版

先按列的角色分配宽度：首列是比较项时给足标签空间，长方法与依据列占较大宽度。尽量使用简短而具体的行标签；必要时在自然语义处换行。

尤其检查首列和窄列末行只剩一个汉字的情况。优先调整列宽、删去赘词或平衡短语换行，再考虑合理缩小字号。调整后保持正常阅读字号，并检查实际单元格换行。

避免单行被分页切断；跨页长表重复表头。宽表可拆为两个有明确关系的表，关键对比仍应容易阅读。实际单元格高度、英文长词、DOI 和 URL 溢出都要在渲染页检查。

## 图与分页

图、图注和紧邻的解释尽量保持在一起。标题与后续内容连排，结合内容长度调整分页和留白。关键概念的首次解释与对应结构、流程或架构图尽量同页。

检查裁切边缘、图中小字、箭头、图例和关键连接。按最终页面尺寸检查图片清晰度和可读性。

## 验收顺序

1. **内容同步**：源稿、图源与 PDF 是同一次构建。图号、参考编号、章节交叉引用一致；不残留已排除方案、旧对照或修订过程文字。
2. **程序核查**：提取 PDF 文字，检查页数、缺字／替代字符、边界溢出、字体及嵌入、图和图注、内部与外部链接。能读取实际表格行时检查孤字换行。程序定位可疑项，语言质量通过全文通读复核。
3. **整份视觉检查**：把全部页面渲染成图片，检查分页、层级、图表和空白；概览用于覆盖全部页，再按可读分辨率查看密集表、公式或代码、关键图、首次介绍、修改页和可疑页。
4. **修复后复验**：重新生成并检查受影响页面及后续分页；若页数改变，清除超过当前页数的旧渲染页，防止误把旧图纳入验收。
5. **记录交付**：记录当前页数、图数、参考数量、实际完成的检查、已知问题及需要时的哈希。逐项记录实际检查结果。

PDF 文本可提取、程序无报错，还需要查看最终页面确认版式。排版验收与研究结论、计算复现、实验或工程性能验证各自记录。

## 维护与交付路径

默认在当前源稿与 PDF 上更新，不按每轮讨论生成版本和备份。用户要求保留里程碑时再另存。更新必要导航、图源说明和接续文件，保留人工维护的入口内容。

给用户可点击的最终文件路径，简述重要改动和验收结果。没有新的资料缺口时说明无需补件；有缺口时附精确清单。缓存清理采用 [接续与清理](handoff-and-cleanup.md) 的依赖检查，保留当前报告可重建所需的字体、库和脚本。
